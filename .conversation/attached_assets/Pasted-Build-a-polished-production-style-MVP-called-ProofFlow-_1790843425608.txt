Build a polished, production-style MVP called "ProofFlow".

ProofFlow is a Web3-powered milestone escrow and proof-verification platform for freelancers, agencies, businesses, contractors, NGOs, and clients.

CORE IDEA:
Instead of trusting screenshots, ratings, or claims that work was completed, ProofFlow lets a client create a project with milestones, a worker submits verifiable proof for each milestone, the client verifies the work, and eventually a blockchain smart contract will release the milestone payment.

IMPORTANT:
This is the MVP phase.

DO NOT implement real blockchain transactions yet.
DO NOT pretend mock transactions are real blockchain transactions.
Build the application architecture so the mock blockchain service can later be replaced by a real Stellar/Soroban implementation without rewriting the frontend.

The application should feel like a serious startup product, NOT a generic hackathon template.
